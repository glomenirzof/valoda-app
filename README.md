# Valoda

PWA для активного словаря латышского: короткие сессии, FSRS, офлайн.
Основа решений — [research/lang-app-research.md](research/lang-app-research.md), архитектура — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Команды

```bash
npm install
npm run dev            # http://localhost:5173/valoda-app/
npm run build
npm run tts:voicetest  # слепой тест голосов → public/voice-test/
npm run content:check  # словарь Tēzaurs + проверка естественности по интернету → статусы фраз
npm run tts:generate   # озвучка только фраз со статусом «ок»
```

## Правило для фраз (обязательно для любой новой или изменённой фразы)

1. Фраза добавляется или меняется только в `content/<lang>/phrases.src.json` (переводы слов — в `lexicon.src.json`). Новые фразы — пачкой: файл `content/<lang>/batches/batch-N.json` и `python -I scripts/content/add_batch.py <lang> content/<lang>/batches/batch-N.json`. Скрипт не пустит фразу, где больше одного нового слова (принцип i+1).
   Если у фразы несколько значений в разных ситуациях, перевод даёт их все с пометкой контекста («До завтра! (при прощании) / до утра»).
2. Сразу после этого запускается `npm run content:check`. Он:
   - проверяет каждое слово по словарю Tēzaurs и разбирает его (`build_phrases.py`), ошибка словаря — фраза не собирается;
   - ищет фразу в корпусе korpuss.lv (LVK2022), а если её там нет — каждое сочетание соседних слов; ищет точное предложение в Tatoeba;
   - делает обратный перевод на русский двумя независимыми переводчиками (Google и Microsoft Azure Translator) и сверяет с нашим переводом;
   - проверяет типичные ошибки ИИ (например, «nav» + не родительный падеж);
   - пишет доказательства и статус в `content/<lang>/auto-check.json`. Статус привязан к точному тексту и переводу: изменённая фраза проверяется заново сама.
3. Статусы: «ок» — найдено у носителей и оба перевода совпадают (с нашим переводом целиком или с одним из его значений через «/»; пометка контекста в скобках не учитывается); «сомнительно» — с причинами; «убрать». Без найденного источника «ок» не ставится. Ручные решения по сомнительным — в `content/<lang>/check-notes.json`. Пометка может убрать фразу или признать синоним в переводе, но не заменит отсутствующий источник.
4. В тренировки попадают и озвучиваются только фразы «ок» (или проверенные репетитором). Озвучка — `npm run tts:generate`: она озвучивает только новые или изменённые тексты.
5. Переводчики: Microsoft (в `.env` нужны `AZURE_TRANSLATOR_KEY` и `AZURE_TRANSLATOR_REGION`, Azure Translator F0) и Tilde — у hugo.gov.lv нет открытого API, поэтому новые тексты переводятся через его сайт (латышский → русский, одной вставкой до 1000 слов) и записываются в `content/<lang>/mt-tilde.json` по точному тексту. Бесплатный адрес Google часто отвечает 429, он необязателен (`--no-google`). Нужно минимум два переводчика.
6. Порядок новых фраз (i+1) пересчитывается на каждой сборке: `add_batch.py` после слияния сам запускает `npm run content:build`, а тот — `scripts/content/order.ts`. Новые фразы встают в общий порядок по одному правилу. Порядок жадный: первые 15 — фразы из 1–2 слов, дальше на каждом шаге самая частотная фраза, которая даёт не больше одного нового слова. Порядок пишется в поле `order` в `phrases.json` (только у фраз «ок»), приложение берёт новые фразы по нему. Отчёт — `content/<lang>/order-report.txt`. Последний шаг `npm run content:check` (`order.ts --check`) падает, если хоть одна фраза в итоговом порядке даёт два новых слова: тогда нужна фраза-мостик, которая введёт одно из них раньше. Женские леммы местоимений из Tēzaurs (tava, mana, tā…) считаются тем же словом, что и мужские.
7. Сомнительные фразы решаются без участия пользователя: поиск конструкции в корпусе (`npx tsx scripts/content/corpus-query.ts "…"`), разговорниках, интернете; затем исправить фразу на вариант носителей, оставить с найденным источником (`evidence` в `check-notes.json`) или убрать.

## Картинки к фразам

Только конкретные предметы, места, еда, транспорт и действия; абстрактные слова — без картинок. Соответствие «слово → картинка» ведётся вручную в `content/lv/images.src.json` (значки Twemoji или конкретный файл Wikimedia Commons; `phraseOverride` — исправление для отдельной фразы, `skipText` — идиомы). `npm run content:images` (входит в `content:build` и `content:check`) берёт файлы с Commons вместе с автором и лицензией (только открытые: CC0, PD, CC BY, CC BY-SA, Apache), сжимает в WebP ≤ 50 КБ в `public/images/lv/`, пишет `public/data/lv/images.json` и отчёт `content/lv/images-report.txt` — все пары «фраза — картинка» и спорные. Картинки видны на знакомстве (S0) и после ответа на узнавании (S1); в настройках — «Картинка вместо перевода» для простых фраз (кроме фраз с отрицанием) и страница «Авторы изображений».

## Тест уровня

При первом запуске (если ещё ничего не выучено) предлагается адаптивный тест; его можно пропустить и пройти позже в настройках. 15–25 вопросов: перевод фраз и слов с русского вводом, окончания после предлогов, «знаю / не знаю» для слов из частотных полос и несколько несуществующих слов против угадывания. Уровень — размер словаря на шкале частотных рангов (A0–B2, примерно). Фразы, которые точно знаешь, сразу попадают в повторения с оценкой «Хорошо» (не больше 15 в день), уже начатые не трогаются. Данные теста — `public/data/lv/placement.json`, собирает `scripts/content/build_placement.py` (запускается в `content:build` и `content:check`).

## Голосовая проверка

Карточка «Скажи»: зажал микрофон — запись, отпустил — запись уходит на распознавание (`gpt-4o-mini-transcribe`) через Cloudflare Worker из папки `worker/`. Ключ OpenAI хранится только в секретах Worker'а. Настройка по шагам, лимиты и стоимость — `worker/README.md`. После публикации Worker'а его адрес вписывается в `src/config.ts` (`VOICE_URL`). Пока адрес пустой, карточка работает на самооценке.

## Ключи для озвучки

Скопируй `scripts/tts/env.template` в `.env` в корне проекта и впиши ключи. `.env` в git не попадает.

Piper (бесплатно, локально) ставится в venv по пути без кириллицы:

```bash
python -m venv %USERPROFILE%\.venvs\valoda-tts
%USERPROFILE%\.venvs\valoda-tts\Scripts\python -m pip install piper-tts
%USERPROFILE%\.venvs\valoda-tts\Scripts\python -m piper.download_voices lv_LV-aivars-medium --data-dir data-cache/piper
```
