# Голосовая проверка: Worker-посредник

Приложение отправляет запись фразы сюда, Worker пересылает её в OpenAI (`gpt-4o-mini-transcribe`, язык `lv`) и возвращает текст. Ключ OpenAI хранится только в секретах Worker'а — в коде приложения и в git его нет.

- Отвечает только приложению: `ALLOWED_ORIGINS` в `wrangler.toml` (сейчас `https://glomenirzof.github.io`).
- Дневной лимит: `DAILY_LIMIT` (сейчас 300 проверок в сутки по UTC), счётчик в Cloudflare KV.
- Распознавателю уходит только звук и язык. Ожидаемая фраза не передаётся (нет `prompt`), поэтому проверка честная.

## Настройка (один раз)

Команды запускаются в папке `worker`:

```bash
cd worker
npm install
```

1. **Аккаунт Cloudflare.** Зарегистрируйся на dash.cloudflare.com (бесплатный тариф Workers). Потом войди из терминала:
   ```bash
   npx wrangler login
   ```
   Откроется браузер — подтверди доступ.

2. **Счётчик запросов (KV).**
   ```bash
   npx wrangler kv namespace create USAGE
   ```
   Команда напечатает `id = "…"`. Вставь это значение в `wrangler.toml` вместо `PASTE_KV_NAMESPACE_ID_HERE`. Это не секрет, его можно прислать мне в чат.

3. **Ключ OpenAI — только в секреты Worker'а.** Создай ключ на platform.openai.com → API keys. Затем:
   ```bash
   npx wrangler secret put OPENAI_API_KEY
   ```
   Терминал спросит значение — вставь ключ туда и нажми Enter. Ключ уходит прямо в Cloudflare, в файлы проекта и в чат он не попадает.
   Советую в platform.openai.com → Settings → Limits поставить месячный бюджет проекта (например, $5): это второй предохранитель после дневного лимита.

4. **Публикация.**
   ```bash
   npx wrangler deploy
   ```
   В конце будет адрес вида `https://valoda-voice.<твоё-имя>.workers.dev`. Он не секретный: пришли его мне или впиши в `src/config.ts` (`VOICE_URL`), затем сборка и деплой приложения.

Если `npm install` пишет про `install-scripts`, выполни `npm install-scripts approve esbuild workerd` и повтори.

## Локальная проверка (необязательно)

Для `npx wrangler dev` ключ кладётся в файл `worker/.dev.vars` (строка `OPENAI_API_KEY=…`). Файл в `.gitignore`, в git не попадает. Чтобы проверять с `http://localhost:5173`, временно добавь этот адрес в `ALLOWED_ORIGINS`.

## Сколько стоит

`gpt-4o-mini-transcribe` — $0.003 за минуту звука (цены OpenAI на ноябрь 2026). Фраза с паузами — 2–5 секунд:

- одна проверка: $0.0001–0.00025 (≈ 0.01–0.025 цента);
- 30 проверок в день: 1–2.5 минуты звука → $0.003–0.0075 в день → **$0.09–0.23 в месяц**;
- даже упор в дневной лимит (300 × 5 с = 25 мин) — $0.075 в день, $2.25 в месяц.

Cloudflare Workers и KV в этих объёмах бесплатны (100 000 запросов и 1000 записей KV в день).
